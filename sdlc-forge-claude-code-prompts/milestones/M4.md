# Milestone M4 — Full Document Chain (FDD, TDD, Dev Plan, UT/SIT/UAT)

**Precondition:** M3 accepted. Read `CLAUDE.md` and `ARCHITECTURE.md` first.
**Goal:** all six phases generate end-to-end on the NovaBank project, with every phase's items linked to predecessors and coverage dashboards live.

## Tasks

1. **Schemas, skills, golden-template records, question-bank entries** for FDD, TDD, Development Plan, and Test Scripts (UT, SIT, UAT). Schemas must embed traceability: every FDD functional item carries `implements: REQ-xxx[]`; TDD items carry `derives_from: FDD-xxx[]`; WBS activities carry `builds: TDD-xxx[]` and `depends_on: WBS-xxx[]`; test cases carry `verifies: [REQ|FDD|TDD]-xxx[]`.
2. **FDD phase**: composer consumes approved BRD + registry + tool knowledge; on approval, TraceabilityAgent extraction → mint FDD items + `implements` links (human-confirmed, as in M3).
3. **TDD phase**: consumes FDD + deep tool knowledge; mints TDD items linked `derives_from` FDD.
4. **Development Plan phase — EstimatorPlanner agent**: decomposes FDD+TDD into the most granular WBS activities; per activity: technology, artifact(s) produced, effort estimate (drawing on estimation-model knowledge artifacts), dependencies, suggested role (RACI). Output includes a machine-readable WBS (table UI with grouping, critical-path-style dependency view) — mint WBS items + links.
5. **Test Design phase — TestDesigner agent**: generates UT, SIT, UAT suites as separate outputs; each case has preconditions, steps, expected results, data needs, and `verifies` links; a coverage matrix view (REQ × test level) with gaps writing `gap` anomalies.
6. **QAAnomalyAgent v1**: after each generation — internal consistency, contradiction vs prior-phase approved outputs, contradiction vs bound knowledge (with evidence pairs), template-mandatory-section completeness. Writes `anomalies` shown in the review editor's right rail.
7. **Coverage dashboards**: project overview page — per-phase status, coverage %, anomaly counts by severity, run cost summary.
8. **Seed**: complete the "finished NovaBank" demo — all six phases generated and approved — alongside an empty second project.
9. **Tests**: per-schema validation fixtures; link-propagation integrity across the chain; coverage computation.
