# Milestone M3 — Traceability Spine

**Precondition:** M2 accepted. Read `CLAUDE.md` and `ARCHITECTURE.md` first.
**Goal:** a first-class traceability registry. IDs are minted only by the traceability service; the RTM is generated from the graph, never written by an LLM.

> **TESTS FIRST.** Write the failing test suite for the traceability engine before any implementation. Show the failing tests, then implement until green. (CLAUDE.md §2.7.)

## Tasks

1. **Traceability service** (`packages/` service consumed by API; becomes traceability-mcp in M5):
   - `create_item(type, text, source_output_section)` → mints sequential codes per project (`REQ-001`, `FDD-001`, …). Minting is transactional and gap-free per type.
   - `link_items(from, to, link_type)` with validity matrix (e.g., FDD `implements` REQ; TC_* `verifies` REQ/FDD/TDD; TDD `derives_from` FDD; WBS `depends_on` WBS). Invalid link types rejected.
   - `get_coverage(phase)` — e.g., % of REQs with ≥1 implementing FDD item.
   - `find_orphans()` — items with no inbound/outbound links where links are expected.
   - `generate_rtm(scope, direction)` — forward (REQ→…→TC) and backward, as structured data.
2. **TraceabilityAgent**: on BRD approval, extract candidate requirements from the approved JSON → human confirms/edits in a "Requirement extraction review" screen → confirmed items minted via the service. Composer agents from now on receive the registry as context and may only reference existing codes; the schema validator rejects unknown codes in output JSON.
3. **RTM Explorer UI**: filterable matrix and graph views; forward/backward direction toggle; click any item → detail drawer with text, source section deep-link, links in/out; export RTM to xlsx.
4. **Coverage & anomalies**: coverage widgets per phase (green/amber/red per CLAUDE.md §5); orphan and broken-chain detection writes `anomalies` (type `orphan`/`gap`); anomaly list view on the project.
5. **Retrofit**: regenerate/seed the NovaBank BRD so a real `REQ-xxx` registry exists.
6. **Tests** (written first): minting concurrency + sequence integrity; link validity matrix; orphan detection; RTM correctness on a fixture graph; unknown-ID rejection in composer output validation.
