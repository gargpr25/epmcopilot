# Milestone M1 — Foundation

**Precondition:** none (first milestone). Read `CLAUDE.md` fully before starting.
**Goal:** a running monorepo where a user can sign in, create a project with Industry/Process/Tool selection, get a frozen Binding Manifest, and an admin can upload, browse, and search knowledge.

## Tasks

1. **Scaffold** the Turborepo/pnpm monorepo per CLAUDE.md §4: `apps/web`, `apps/api`, `packages/shared`, `packages/db`. Add docker-compose (Postgres 16 + pgvector, Redis, MinIO), `.env.example`, CI workflow (lint + test + build), pino logging, OpenAPI generation.
2. **Database**: implement the full Drizzle schema from CLAUDE.md §6 (all tables now, even those used later — the schema is the contract). Migrations + `pnpm db:migrate` + `pnpm db:seed`.
3. **Auth & RBAC**: Auth.js with local credentials (OIDC-ready config). Roles per CLAUDE.md §4 enforced in Fastify middleware on every route. Seed one demo user per role.
4. **Knowledge module**: upload (docx/pdf/md/xlsx) → parse → chunk → embed (BullMQ job, SSE progress) → store in `artifact_chunks`. Taxonomy tree UI (the 8 branches: Governance, Industry, Process, Tool, OutputDocumentSkills, Templates, Examples, KnowledgeRepo) with drag-to-place, versioning (immutable versions), review status, owner. Hybrid search endpoint (vector + keyword + taxonomy filter) with a search UI.
5. **Project creation flow**: wizard — name/client → select Industry, Process, Tool(s) from taxonomy → system resolves the **Binding Manifest** via the algorithm in CLAUDE.md §6 → manifest review screen (grouped by branch, priority order visible, pin/exclude controls) → freeze. Manifest stored versioned; re-bind is an explicit, audited action.
6. **Admin console v1**: knowledge artifact CRUD, template upload (file + metadata only at this stage), `doc_type_schemas` editor (JSON schema with validation preview).
7. **EY theme**: implement the design system from CLAUDE.md §5 — dark ink sidebar, yellow accents, Inter, shadcn theme tokens. App shell: sidebar nav (Projects, Knowledge, Admin), top bar, ⌘K palette stub.
8. **Seed**: taxonomy with 2 industries × 2 processes × 2 tools; 6–8 starter knowledge artifacts with realistic content; demo users.
9. Write tests for the **binding-resolution algorithm** (inheritance, priority ordering, pin/exclude, freeze immutability) and chunk/search round-trip.

## Acceptance Checks (run and print results)

- [ ] `docker-compose up` + `pnpm dev` from clean clone starts web, api, db, redis, minio.
- [ ] Sign in as Project Lead; create a project selecting BFSI × Record-to-Report × CCH Tagetik; see a resolved manifest whose contents change when a different tool is selected.
- [ ] Pin one artifact, exclude one, freeze; reopening shows the frozen manifest; `audit_log` has the freeze event.
- [ ] Upload a multi-page docx as Knowledge Curator; chunks + embeddings exist; search returns it with taxonomy filter applied.
- [ ] A Viewer role cannot create projects or upload knowledge (server-side rejection, not just hidden UI).
- [ ] Binding-resolution test suite green; CI green.
